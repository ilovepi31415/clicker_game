# Make a Million: A Clicker Game

## Summary
Have you ever wanted to make a Million Dollars? Well, now you can (in this game). Click your way there, earning upgrades and more as you go. Your progress will be saved if you exit the game, so you can come back stronger the next time. Even once you're done, keep trying to improve your time and be the fastest millionaire in the universe.

## Motivation
I created this to learn about the Pygame development process, and partially just to make something fun

## Requirements
This program was created in Pygame, so it and Python are required to run it.

## Quick Start
Run the index.py file, and the game will start. Click your way to a Million Dollars, after which you will see the time it took you to reach it.

## Usage
The large red button is the first step to making money, clicking it will give a constant amount displayed in dollars. The buttons stats can be upgraded

At a later stage, tic-tac-toe will become available to play, rewarding the user with wins to be spent on other upgrades

The final game is a math quiz with three answers given for each equation. Correct answers will increase your IQ score and allow other upgrades to be bought

At One Million Dollars, a trophy will be given to the user, along with the time taken to reach the goal down to the frames

Progress will reset if `savefile.json` is deleted or the clear progress X button is clicked in game
